## Next step

Nothing is open in Task 5.
Wave 3's sibling tasks (6 craft, 7 review, 8 spawn) and then Task 9 are next; Task 9 consumes this skill's resolution behavior.
Four harness facts are worth carrying into any task that authors an eval, all established by execution here.

1. `Write` is a gated tool: a case that writes a file needs `--allow-tools Write` on every invocation, or the harness refuses the grant and the file graders cannot pass.
2. An `llm` grader's `focus: {source: file, path: ...}` takes a literal relative path, never a glob; the `file_exists` grader does take a glob.
3. Turns injected by `context.history_file` do not appear in the trace a judge reads, so a replay case cannot be graded on what the injected turns contained.
4. A `focus: last_message` judge never sees the case prompt, so it cannot know what the user's description fixed. Anything the criteria asks it to check against the description must be visible in the message itself, and a row about a field the description settled off-screen (here, `kind`) reads to the judge as a gap wrongly labeled stated.
5. A `prompt.md` body reaches the agent verbatim, so acceptance prose in the body is a leaked rubric. It belongs in `expected_outcome: |` frontmatter, which the harness never delivers.
